# Fase 9 — Monetización (PENDIENTE DE DECISIÓN — NO CONSTRUIR TODAVÍA)

## Estado
Ricardo aún no ha decidido el modelo final. Las dos opciones sobre la mesa hasta ahora:
- Cuota fija mensual al asesor
- Cobro únicamente en los meses que el asesor cierra una venta (no cuota fija)
